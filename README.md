# Survivor Adventure

## Projeto inicial jogável em navegador

Este repositório contém um MVP jogável em 3D no navegador, com foco em um protótipo de aventura/sobrevivência.

## Como executar

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

3. Abra no navegador a URL mostrada pelo Vite, normalmente:

```bash
http://localhost:3000
```

## Controles

- W/A/S/D ou setas: mover
- Espaço: pular
- Clique do mouse ou tecla E: atacar
- Objetivo: coletar 5 pedras de poder e chegar até o portal

## Objetivo do MVP

- mundo 3D explorável
- personagem em terceira pessoa
- câmera seguindo o protagonista
- movimentação e pulo
- ataque básico
- coleta de itens
- portal liberado ao terminar a missão
